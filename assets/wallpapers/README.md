# Wallpapers Guide

Use this guide to add safe, high-quality anime-style wallpapers for AnimeTab.

## Copyright-Safe Sources

Use only images that are licensed for reuse or that you created yourself:

- Pixabay: search with the `anime` tag and verify license details.
- Unsplash: use illustration/anime-inspired artwork with Unsplash license compliance.
- Wallhaven: use only original works with **General** rating and verify upload rights.
- AI-generated images: create your own assets with prompts and keep generation records.

Do not use copyrighted anime screenshots, official posters, or fan art without clear licensing permission.

## Image Requirements

- Format: WebP
- Minimum resolution: 1920x1080
- Target file size: under 500 KB
- Required naming: `bg1.webp`, `bg2.webp`, ..., `bg15.webp`
- Location: `assets/wallpapers/`

## Compression Workflow (Squoosh)

1. Open [Squoosh](https://squoosh.app/).
2. Drag your wallpaper image into the app.
3. Select **WebP** output format.
4. Reduce quality until file size is under 500 KB while preserving clarity.
5. Export and rename to the required `bgN.webp` pattern.
6. Copy exported files into `assets/wallpapers/`.
